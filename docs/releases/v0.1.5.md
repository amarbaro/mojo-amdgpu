# mojo-amdgpu-public v0.1.5

**Released:** 2026-11-09 · **Commit:** `a09e2f9` · **Previous:** [v0.1.4](v0.1.4.md)

## What it does

AMD GPU telemetry for Mojo read straight from sysfs, hwmon and KFD, with no ROCm and no `rocm-smi`: VRAM, GTT, busy, temperatures, power, clocks, fan, and KFD nodes, for every AMD card, picking the one with the most VRAM by default.

## Highlights

- The quickstart now runs from an installed package: it reads the live `/sys`, and takes a sysfs root as its first argument to run without an AMD card.

## Changes

### Fixed
- `examples/quickstart.mojo`: read `/sys` by default instead of the repo-only `tests/fixtures/sys`; an optional argument selects another sysfs root.
